**Estudiante:** Carolina Delgado

## Descripción del Proyecto
Aplicación en React para una tienda de libros que permite explorar distintas categorías literarias, consumiendo un servicio REST mockeado con MSW (Mock Service Worker), navegando a través de React Router e implementando manejo optimizado de peticiones HTTP, control de estados de carga y gestión de errores.
